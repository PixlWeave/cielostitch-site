Capabilities

Every tool a scientist needs

CieloStitch combines sub-pixel alignment algorithms, GPU-accelerated pipelines, and lossless scientific metadata handling into a single, unified workflow.

  • Sub-Pixel Stitching

    Phase-correlation and feature-point algorithms achieve alignment accuracy down to 0.1 px, eliminating visible seams across high-magnification mosaics.

    Alignment

  • Multi-Spectral Alignment

    Register frames captured across UV, visible, NIR, and thermal bands simultaneously, preserving spectral fidelity for downstream analysis pipelines.

    Spectroscopy

  • GPU-Accelerated Pipelines

    CUDA and Metal backends offload convolution, warping, and blending to the GPU — processing 10 000-frame survey datasets up to 40× faster than CPU-only tools.

    Performance

  • Distortion Correction

    Built-in lens and optical system calibration models — including radial, tangential, and field-curvature distortions — ensure metrically accurate output.

    Calibration

  • FITS & Metadata Preservation

    Reads and writes FITS, GeoTIFF, HDF5, and ENVI formats with full header propagation, so WCS coordinates, exposure data, and instrument parameters travel with every output.

    Formats

  • Automated Batch Processing

    Schedule and queue thousands of mosaic jobs with configurable priority rules, dependency graphs, and failure-recovery checkpoints — hands-free overnight runs.

    Automation

  • WCS-Aware Projection

    Native support for all FITS World Coordinate System projections — gnomonic, Mollweide, HEALPix and more — letting you output to any reference frame or coordinate system.

    Astrometry

  • Noise & Artifact Removal

    Cosmic-ray rejection, hot-pixel masking, and multi-frame sigma clipping are applied prior to stitching, producing clean science- grade mosaics in a single pass.

    Image Quality

  • Scriptable Python API

    Every pipeline stage is accessible through a clean Python API, enabling reproducible research workflows, Jupyter notebook integration, and CI-driven data reduction runs.
