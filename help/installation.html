Installation and System Requirements

Check whether your system is a good fit for CieloStitch, then follow the basic install steps and first launch checks below.

Supported platform

The current public desktop release is for Windows. If you are checking support for another operating system, use the website download section and release notes as the current source of truth.

Minimum practical system requirements

  • OS: Windows 10 or Windows 11, 64-bit.
  • CPU: A modern dual-core processor is enough for smaller projects.
  • Memory: 8 GB RAM is a reasonable floor for basic use.
  • Display: 1024×768 works, but larger screens are more comfortable for review.

Recommended system requirements

  • CPU: A modern 4-core processor or better improves responsiveness on larger jobs.
  • Memory: 16 GB or more is the safer baseline for higher-resolution mosaics.
  • Storage: Fast SSD storage helps when reading many inputs and writing large outputs.
  • Display: 1920×1080 or higher makes panel review and result inspection easier.

Install the application

  1. Download the latest Windows installer from the homepage or GitHub Releases.
  2. Run the installer and complete the setup on your machine.
  3. Open CieloStitch and confirm that the main window appears normally.
  4. Load a small panel set first so you can verify the workflow before using a larger project.

First launch expectations

On first launch, keep the goal simple: make sure the app opens, your images can be added, and a small test stitch completes cleanly. Use a representative test set instead of a full production mosaic for this first check.

Common installation issues

  • Installer blocked: Check that the download completed successfully, then run it again locally.
  • App opens slowly: First launch can feel slower on systems with less memory or slower disks.
  • Large jobs feel constrained: This is usually a hardware or project-size issue, not an installation issue.
